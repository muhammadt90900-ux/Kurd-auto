# 🚗 Kurd Auto – Car Parts Marketplace

A full-featured Flask marketplace for car parts in Kurdistan/Iraq. Supports sellers, buyers, VIP plans, chat, reels, and multiple payment gateways.

## Features
- User roles: Seller, Buyer, Admin
- Email verification via OTP
- VIP plan (unlimited uploads)
- Add parts with image/video
- Reels (short videos) with like/view tracking
- Real-time chat
- Favorites & Compare
- Reviews & ratings
- Notifications
- Multi-language (Kurdish, Arabic, English)
- Payments: FastPay, NassWallet, FIB (First Iraqi Bank)
- Admin panel with user/limits management
- SEO-ready, sitemap, responsive design

## Tech Stack
- Flask 3.0
- SQLAlchemy, Flask-Login, Flask-Limiter
- Bootstrap 5 + custom CSS
- SQLite (can be swapped to PostgreSQL/MySQL)
- Gunicorn for production
